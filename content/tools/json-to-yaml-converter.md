## About JSON and YAML

**JSON** is JavaScript Object Notation — the data language of APIs and the modern web. **YAML** is the human-friendly data format used for config files and DevOps. Moving data between the two by hand is slow and error-prone — this converter does it in one click, preserving the structure of your data.
