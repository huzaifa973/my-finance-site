## How to use this resource

1. Identify your job type first: everyday, official, photo, or booklet — then apply that row of settings.
2. Always open the print preview and check page count, orientation, and paper size before printing.
3. For long documents, print one test page first to catch scaling or margin problems early.
4. For official forms, never use Fit to page — use Actual size so fields and boxes print at true size.
5. If something looks wrong, check the problem-fix table in the download before reprinting the whole job.

Tape the cheat sheet to the wall near your printer — the whole household or office will use it within a week.

## Frequently asked questions

**Why does my PDF print smaller than it looks on screen?**

Your scaling is set to Fit to page, which shrinks the document to fit the printable area. Switch to Actual size (100%) when the true size matters, such as for forms.

**Should I print official forms in color?**

Only if the form has color elements that matter, like stamps or colored fields. Most official forms are designed for black-and-white printing and are accepted either way.

**What does flip on long edge mean?**

It controls how double-sided pages turn. Flip on long edge is for portrait documents you read like a book; flip on short edge is for landscape pages or documents bound at the top.
