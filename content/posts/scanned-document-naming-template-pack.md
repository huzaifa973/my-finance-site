## What's inside this naming pack

The core of the pack is the formula itself: date, category, document name, version, separated by underscores, with hyphens inside names and no spaces anywhere. Because the date comes first, files sort chronologically on any device without special software. The category word tells you what kind of document it is at a glance, and the version tag ends the 'final2' problem forever.

## How to use this resource

1. Create the eight category folders on your computer or cloud drive before you scan anything new.
2. After each scan, name the file immediately using the formula — never leave a scan with its default name.
3. Use the date the document was issued, not the date you scanned it, so sorting reflects the document's life.
4. When a document changes, save it as v2 instead of overwriting v1, so you can always go back.
5. Once a month, spend ten minutes moving strays into the right folder and backing everything up.

The system only works if naming happens at scan time — a file named later is a file named never.

## Frequently asked questions

**Why put the date first in the filename?**

Because date-first names sort chronologically on every device and operating system, with no special software. It is the single change that makes a folder searchable at a glance.

**Should I scan in color or grayscale?**

Grayscale for most documents: it keeps files small and text sharp. Use color only when color carries information, like signatures, stamps, or photographs.

**What resolution should I scan at?**

300 DPI for documents you may print or submit officially, 150 DPI for reference copies. Higher than 300 DPI mostly just creates huge files with no visible benefit.
