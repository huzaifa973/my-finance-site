Sometimes you need to share a document — a contract, a tax form, medical records — and plain email just isn't safe enough. A password on the PDF itself is the simplest way to add a real layer of protection, and you don't need expensive software to do it. Here's how to password-protect a PDF online, for free, in about a minute.

## Why password-protect a PDF?

A PDF password encrypts the file's contents. That means:

- **Only people with the password can open it.** Even if the email or download link leaks, the file stays unreadable.
- **It works everywhere.** Encrypted PDFs open in Adobe Reader, Preview on Mac, Chrome, and every major PDF app — the recipient just enters the password once.
- **It's compliance-friendly.** For contracts, invoices, HR paperwork, and client files, a password is often the minimum expected safeguard.

A password isn't invincible — a determined attacker with enough computing power could eventually crack a weak one — but against casual snooping, lost USB drives, and forwarded emails, it's genuinely effective.

### Step 3: Choose a strong password

This is the part that actually matters. A PDF password is only as strong as the password itself:

- Use **12 or more characters**, mixing uppercase, lowercase, numbers, and symbols.
- Avoid names, birthdays, company names, and dictionary words — these are the first things cracking tools try.
- A passphrase works great: four or five random words like `crisp-lemon-tower-57-mile` is both strong and memorable.

- For one-time sharing, agree on the password verbally beforehand.

## What kind of encryption do you get?

PDF tools that do this properly use **AES-128 or AES-256 encryption** — the same standard used by banks and governments. Older "PDF encryption" methods (40-bit RC4, from the 1990s) are effectively broken, so a good tool uses the modern standard. DollarWise's protector applies strong encryption by default, so you don't have to think about algorithms.

Two password types exist in the PDF spec, and it's worth knowing the difference:

| Type | What it does |
|---|---|
| **User password** | Required to open and view the document. This is the one you want. |
| **Owner password** | Controls permissions (printing, copying text) — but can be stripped by many free tools, so don't rely on it for real security. |

When you set a user password, the entire document is encrypted. That's the lock that matters.

## Common mistakes to avoid

1. **Using a weak password.** `Password123` on a PDF takes seconds to crack. Use the passphrase method above.
2. **Sending the password with the file.** Defeats the entire purpose. Use a second channel.
3. **Forgetting the password yourself.** Encryption is a one-way door — if you lose the password and didn't keep the original, the file is effectively gone. Save it in a password manager.
4. **Uploading sensitive files to sketchy sites.** Many "free PDF" sites send your document to their servers and keep copies. ## Sharing encrypted PDFs professionally

If you send protected documents regularly — invoices, reports, client contracts — build a small routine:

- Keep a consistent naming convention, e.g. `invoice-1042-protected.pdf`, so you never confuse secured and unsecured copies.
- Maintain a secure password vault (not a spreadsheet) with the passwords you share, or better, use unique passphrases per client.
- Tell recipients in advance: "I've sent you a password-protected PDF — the password is coming by text." That way they don't think the file is corrupted.
