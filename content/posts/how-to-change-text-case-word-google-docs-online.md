Retyping it is the slow way. Changing text case — flipping text between UPPERCASE, lowercase, Title Case, and other styles — takes seconds once you know where the button lives.

Here's how to do it in Microsoft Word, in Google Docs, and with a free online tool that handles every style in one click.

## How to change text case in Microsoft Word

Word has a built-in **Change Case** feature — it's just buried enough that most people never find it.

### Method 1: The keyboard shortcut (fastest in Word)

1. Select the text you want to fix.
2. Press **Shift + F3** (Windows). On Mac, this works in Word too, though some versions remap it.
3. Press it repeatedly — it cycles through three styles:
   - **Sentence case.** (capitalizes the first word)
   - **lowercase**
   - **UPPERCASE**

For quick fixes — de-caps-ing an accidentally shouted paragraph or capitalizing a heading — this is all you need.

### Method 2: The ribbon button (more control)

1. Select your text.
2. On the **Home** tab, find the **Font** group and click the **Aa** icon (Change Case).
3. Choose from Sentence case, lowercase, UPPERCASE, Capitalize Each Word, or tOGGLE cASE.

This is the better route when you need a specific style and don't want to cycle through Shift + F3 guesses. Note that Word's list is short: it covers everyday writing but not programmer styles like camelCase, snake_case, or kebab-case.

## How to change text case in Google Docs

Google Docs is trickier — there is no dedicated Change Case button on the toolbar, which is why "how to change text case in Google Docs" gets asked constantly.

### Method 1: The Capitalization menu

1. Select the text.
2. Go to **Format > Text > Capitalization**.
3. Pick one of three options: **lowercase**, **UPPERCASE**, or **Title Case**.

That's it — three styles, no sentence case option, and no keyboard shortcut. It covers the basics: normalizing an all-caps paragraph or capitalizing a heading.

### Method 2: Change case on mobile

In the Google Docs mobile app, the path is similar: select text, tap the **format** icon (the "A" with lines), then look for text options. The capitalization submenu behaves the same as desktop.

### What Google Docs can't do

Google Docs won't give you sentence case (capitalizing only the first word of each sentence), Capitalize Each Word for presentation slides, or any of the developer styles. If you hit that wall regularly, the online method below is the fix — one tab, every style.

## The main case styles and when to use each

Not every style fits every job. Here's a quick cheat sheet:

- **UPPERCASE** — headings that need punch, form fields that require all caps, legal boilerplate. Use sparingly in prose — whole paragraphs in caps are hard to read and read as shouting.
- **lowercase** — email subjects you want to look casual, usernames, tags, or normalizing messy pasted text before styling it properly.
- **Sentence case** — the default for normal writing: capitalizes the first word of each sentence, like this sentence. The go-to when cleaning up pasted or OCR'd text.
- **Title Case** — headlines, essay titles, book titles, presentation slides. Major words get capitalized ("How to Change Text Case in Word and Google Docs").
- **Capitalize Each Word** — every word gets a capital, including small ones ("How To Change Text Case") — common in posters, certificates, and slide titles.
- **camelCase / PascalCase** — code: variable names (`userProfileSettings`) and class names (`UserProfileSettings`). Developers convert phrases into code-ready names daily.
- **snake_case / CONSTANT_CASE** — constants and database fields (`USER_PROFILE_SETTINGS`), Python and C-style naming.
- **kebab-case** — URL slugs, file names, and CSS classes (`how-to-change-text-case`).
- **aLtErNaTiNg / InVeRsE** — social captions, memes, and playful branding.

## Mistakes to avoid when changing text case

**Don't "fix" case by retyping.** If you're retyping more than a sentence, you've already lost — use Shift + F3 in Word, the Capitalization menu in Google Docs, or an online converter.

**Watch proper nouns in Title Case.** Automatic title casing capitalizes every word, but it won't know that "iPhone" or "eBay" should keep their unusual capitalization, or that "and" should stay lowercase in Chicago style. Proofread branded terms after converting.

**UPPERCASE whole paragraphs sparingly.** Studies on readability consistently show that all-caps text is harder and slower to read. Reserve it for short headings and emphasis, not body text.

**Check language-specific quirks.** In German, for example, nouns are capitalized — a blind lowercase conversion can change meaning. Auto-conversion is a starting point, not a substitute for a final read.
