Every developer needs realistic test data — for a demo, a tutorial, a unit test, or a portfolio project — and hand-writing it is tedious while random generators produce nonsense. These one hundred JSON sample datasets cover the shapes real apps use: users, products, orders, posts, tasks, events, books, movies, employees, and more. They are written for developers, students, and tutorial authors who need data that looks real enough to build against.

## What's inside this resource

Each dataset is a small, valid JSON object with sensible field names and plausible values, so it drops straight into code, a database seed, or an API mock. The pack starts with twenty distinct shapes and extends them with varied IDs, so you can use several related datasets in one project without collisions. Replace the example values with your own domain data once the structure is proven — the shapes are the reusable part.

### Why do some datasets share a shape?
