PDFs feel safe because they look finished and hard to edit — but a PDF can quietly carry far more than its visible pages. Hidden text, metadata, comments, and tracked changes have leaked sensitive information from documents that looked perfectly clean. Before you share a contract, medical record, financial statement, or legal document, it is worth running through a proper security check.

This checklist walks you through the full process: cleaning the document, locking it down, choosing a safe way to send it, and confirming it arrived. Use it every time a document contains personal data, financial details, health information, or anything you would not want published. A few minutes of checks can prevent a leak that takes months to undo.

Why does this level of care matter? Because PDF leaks rarely come from hackers breaking encryption — they come from ordinary oversights. A contract shared with tracked changes still visible, a report whose blacked-out names can be revealed by copying the text underneath, a file whose metadata names the author and the draft history. Each of these has embarrassed real organizations, and each is preventable with a two-minute check. Think of this checklist as that check: cheap insurance against the kind of mistake that is obvious only in hindsight.

## What's inside this resource

The checklist is organized in four stages. First, clean the document itself — remove hidden data and truly redact sensitive text rather than just covering it. Second, apply protection: passwords, permissions, and encryption. Third, choose a secure delivery method and verify the recipient. Finally, follow up after sending: confirm receipt, track access where possible, and revoke or expire links when the document is no longer needed.

## How to use this resource

Work through the list in order before every sensitive share, and keep a copy of the checklist with your document templates so the steps become habit. For routine documents, the first two stages take only a few minutes once you know your tools. For highly sensitive material, complete all four stages and consider having a second person verify the redacted file before it goes out.

## Frequently asked questions

### Is a password-protected PDF enough for sensitive documents?

It helps, but it is not the whole answer. Combine a strong password with proper redaction, metadata removal, and a secure delivery channel — and share the password separately from the file.

### What is the difference between redaction and covering text?

Covering text with a black box only hides it visually; the original text is still in the file and can be copied out. True redaction permanently removes the text and its underlying data.

### How should I share the PDF password?

Never in the same message as the file. Send it through a different channel — for example, a phone call or a separate messaging app — so one intercepted message is not enough.
