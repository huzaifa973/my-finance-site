A sensitive PDF is only as safe as its weakest copy: the one emailed to a personal inbox, the draft left in a downloads folder, the “redacted” file where black boxes hide text that is still selectable underneath. This twenty-point checklist walks through the full life of a sensitive PDF — creating, sharing, storing, and finally deleting it — so private information stays private. It suits offices, clinics, schools, and anyone who handles contracts, medical records, or personal data.

## What's inside this resource

The checks are grouped by stage because most leaks happen at handoffs: creation (real redaction, not paint-over), sharing (links, passwords, expiry), storage (encryption, access), and disposal (deletion that actually deletes). Work through them before a file leaves your hands, not after.

## The resource (sample)

1. Redact with a real redaction tool — never cover text with black boxes or images.
2. After redacting, search the PDF for the hidden terms to confirm they are gone.
3. Remove metadata: author, title, and hidden revision history can leak names and dates.
4. Password-protect with a strong, unique password — never the company name or “123456”.
5. Share via a link that expires, not an open attachment in an email.
6. Confirm the recipient's address before sending — autocomplete causes more leaks than hackers.
7. Store sensitive PDFs in an encrypted folder or drive, not on the desktop.
8. Limit access to named people, not “everyone with the link.”
9. Delete local copies after the work is done, including downloads and temp files.
10. Empty the trash after deleting — files in trash are still files.

## How to use this resource

1. Run the checklist before sharing, not after — prevention is the whole point.
2. Treat a redaction check as mandatory: search for the hidden terms in the finished file.
3. Keep one master list of who has access to each sensitive file, and review it quarterly.
4. When in doubt, share less: a summary often replaces a full sensitive document.
5. Train anyone who handles these files — the checklist only works if the team uses it.

A resource is only useful when it gets used — pick one item today, use it as written, and adapt it from experience rather than from theory.

## Frequently asked questions

**Is a black box over text a proper redaction?**

No. Painted-over text usually remains in the file and can be copied or revealed. Use a real redaction feature that removes the underlying text.

**Should I password-protect every sensitive PDF?**

Yes, with a strong unique password shared through a different channel than the file itself. Passwords stop casual access; they do not replace careful sharing.

**What about files I already shared?**

You cannot reliably recall a sent file. Change any credentials inside it, notify affected people if data leaked, and tighten the process for next time.
