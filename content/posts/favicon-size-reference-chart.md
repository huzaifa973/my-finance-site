That tiny icon in the browser tab does outsized work: it's your brand in bookmarks, history, home screens, and search results. But every platform wants a different size — 16 pixels here, 512 there, an SVG for Safari, a manifest for Android — and guessing leads to blurry tabs and broken home-screen icons. This reference chart lists every favicon size that matters in 2026, organized by platform, with the exact file names browsers expect. It also gives you the five-file minimal set that covers 99% of cases and a copy-paste HTML snippet. Web designers, developers, and site owners can go from a single 512px master to a complete favicon package in minutes.

## How to use this chart

1. Design one master icon at 512x512 or larger — everything else is generated by downscaling, never upscaling.
2. Export the five minimal-set files first; add the rest only if your audience needs them (Windows tiles, pinned tabs).
3. Simplify the artwork ruthlessly: bold shapes and one or two colors, because fine detail vanishes at 16x16.
4. Paste the HTML snippet into your site's `<head>` and reference the manifest for Android icons.
5. Test at real sizes: open a browser tab (16px), bookmark the page, and add it to a phone home screen before calling it done.

The single most common failure is designing a detailed logo and shrinking it — at 16 pixels it becomes a smudge. If your tab icon is a blur, design a simplified small-size version rather than fighting the downscale.

## Frequently asked questions

**What is the standard favicon size?**
The classic standard is a multi-size favicon.ico containing 16x16, 32x32, and 48x48 pixel versions. Modern browsers also accept a scalable favicon.svg, which stays sharp at any size.

**What size should the Apple touch icon be?**
180x180 pixels, saved as apple-touch-icon.png. iOS uses it when someone adds your site to their home screen. No gloss or rounded corners needed — iOS applies those itself.

**Do I really need all these favicon sizes?**
No. Five files cover 99% of cases: favicon.ico (multi-size), favicon.svg, apple-touch-icon.png (180x180), the two Android Chrome PNGs (192 and 512), and an og-image.png for social previews.
