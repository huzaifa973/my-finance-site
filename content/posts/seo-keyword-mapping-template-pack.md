Most websites do not have a traffic problem — they have a mapping problem. Two pages accidentally target the same keyword and compete with each other, important topics never get a dedicated page at all, and nobody can say which page is supposed to rank for what. A keyword map fixes all of that in one simple document: every page gets one primary keyword, a handful of supporting terms, and a clear search intent. It is the cheapest SEO system a small site can adopt, and it takes less than an hour to set up.
This pack gives you everything you need to build and maintain that map: a page-level mapping table, a topic-cluster template, a search-intent checklist, and a monthly review sheet. It suits bloggers, shop owners, and anyone managing a growing site with a spreadsheet and no expensive tools. The sample template below shows the format; the free download holds the complete pack, ready to copy into your own spreadsheet.

## What's inside this template pack

The pack opens with the page keyword map itself — one row per page with columns for URL, primary keyword, intent, supporting keywords, title idea, and status. That single table becomes your site's source of truth: before writing a new post, you check the map first, which prevents duplicate targeting and reveals gaps where a topic has no page yet.
Next comes the cluster template, which groups a broad pillar topic with its supporting pages so internal links flow naturally from the cluster to the pillar. Then the intent checklist helps you match each keyword to what the searcher actually wants — learning, comparing, or buying — so your page format fits the query. Finally, the monthly review sheet turns keyword mapping from a one-time chore into a light routine: new targets, updated pages, retired keywords, and next month's focus cluster.

## How to use this resource

1. List every page on your site in the map table, one row per page, even the ones you think are unimportant.
2. Assign exactly one primary keyword per page. If two pages share one, rewrite one of them to target something different.
3. Add two to four supporting keywords that genuinely belong on the page, and note the search intent for each row.
4. Build one cluster per month: a pillar guide plus four to six supporting pages, linked together.
5. Run the monthly review sheet: retire keywords that no longer fit, and set next month's focus cluster.

A map only works if it stays current — update it every time you publish, not once a year.

## Frequently asked questions

**What is a keyword map?**

A keyword map is a simple table that assigns each page on your site one primary keyword plus supporting terms. It prevents two pages from competing for the same keyword and shows which topics still need a page.

**How many keywords should one page target?**

One primary keyword and two to four supporting keywords. More than that usually means the page is trying to do too many jobs, and splitting it into two focused pages works better.

**Do I need paid SEO tools to use this pack?**

No. The templates work in any spreadsheet or document, and free tools like Google Search Console can supply the ranking data for your monthly review.
