# Portfolio Website Prompt 🎨

Freelancers and creators: stop paying for templates. One prompt builds your entire portfolio — hero, gallery, services, testimonials, contact.

## The prompt

<div class="prompt-wrap">
<button class="btn btn-sm" onclick="copyPrompt(this)">📋 Copy prompt</button>

<pre class="prompt-text"><code>Build an elegant portfolio website for [YOUR NAME], a [PROFESSION, e.g. wedding photographer based in Austin].

Sections in order: 1) full-screen hero with name, tagline, and 'View my work' CTA over a striking background image, 2) about section with portrait photo and 3-paragraph story, 3) filterable project gallery (categories: [CATEGORY 1, CATEGORY 2, CATEGORY 3, e.g. Weddings, Portraits, Events]) with lightbox viewing, 4) services + starting prices, 5) 3 client testimonials, 6) contact form + Instagram/email/social links.

Style: dark sophisticated theme, serif display font paired with clean sans body, smooth reveal-on-scroll animations, masonry gallery, generous whitespace, fully responsive. No lorem ipsum — write realistic placeholder copy I can edit.</code></pre>
</div>

## Best AI tools for this

- **Framer AI** — designer-grade portfolios, publish in one click
- **Lovable** — quick full-site generation with editing
- **v0** — clean code you can hand to a developer
- **Durable AI** — fastest path if you want it done in 60 seconds

## Make it yours

- **[PROFESSION]** — "brand designer", "fitness coach", "real-estate agent", "makeup artist"
- **Categories** — use the words clients actually search for
- **Style** — "light airy minimal", "bold brutalist", "warm editorial" completely change the feel

## Pro tips

- Your **best 9 projects** beat 50 mediocre ones — curate ruthlessly.
- Add one line under each project: what you did + the result.
- Put your contact button in the navbar — never make clients hunt for it.
