# Video File Format Cheat Sheet for Creators

Every creator has hit the same wall: a video that will not upload, plays without sound on a client's phone, or exports at ten times the needed size. The cause is almost always the format. This cheat sheet explains the twenty formats creators actually meet — MP4, MOV, WebM, ProRes, AV1, and the legacy formats to avoid — in plain language: what each one is for, where it plays, and when to choose it. It is written for YouTubers, course creators, editors, and social media managers.

## Resource

1. MP4 (H.264) — universal playback, YouTube, social, web embeds
2. MP4 (H.265/HEVC) — smaller files, newer devices, 4K streaming
3. MOV (ProRes) — editing master, high quality, huge files
4. WebM (VP9) — web playback, open format, good compression
5. AVI — legacy Windows format, large files, avoid for delivery
6. MKV — flexible container, subtitles and multiple audio tracks
7. GIF — short loops, no audio, social memes only
8. FLV — obsolete Flash format, do not use for new work
9. WMV — legacy Windows delivery, limited compatibility today
10. MPEG-2 — broadcast and DVD legacy format
11. ProRes 422 — editing intermediate, Mac workflows
12. DNxHD/HR — editing intermediate, Avid workflows
13. H.264 High Profile — best balance for most uploads
14. H.265 10-bit — HDR delivery, YouTube and streaming
15. VP8 — older WebM codec, still seen in browsers
16. AV1 — newest royalty-free codec, best compression, slower encodes
17. Vertical 9:16 MP4 — Shorts, Reels, TikTok native format
18. Square 1:1 MP4 — feed posts that work on all platforms
19. 4K MP4 — high-resolution delivery, larger uploads
20. 1080p MP4 — the safe default for most creators
