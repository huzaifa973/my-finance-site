# PDF Print Bleed Checklist for Designers

Nothing ruins a print job faster than a white edge where a full-bleed photo should be. This twenty-point checklist is the preflight pass designers run before sending any PDF to print: bleed size, safe margins, color mode, resolution, fonts, and export settings, all in the order a print shop checks them. It is built for graphic designers, print shops, and small business owners preparing flyers, menus, booklets, and packaging.

## Resource

1. Bleed set to 3mm (0.125 in) on all four sides
2. Critical text kept at least 5mm inside the trim edge
3. Images extended fully into the bleed area, not stopping at trim
4. Document color mode is CMYK, not RGB
5. All images are 300 DPI at final print size
6. Fonts embedded or outlined before export
7. Crop marks and bleed enabled in the PDF export settings
8. Page size matches the printer's requested trim size exactly
9. No white hairlines at folds — backgrounds cross the fold
10. Spot colors converted or confirmed with the printer
11. Black text is 100% K, not rich black, for small type
12. Large black areas use rich black (C40 M30 Y30 K100)
13. Overprint settings checked for white elements
14. Proofread once more after export — export can shift text
15. PDF/X-1a or PDF/X-4 standard used as the printer requested
16. Layers flattened where the printer requires it
17. File name includes job name, size, and version
18. A printed proof or on-screen soft proof has been approved
19. Printer's paper stock and finish confirmed before sending
20. Final file checked on a different device before delivery

## How to use

1. Pick the items that fit your situation and ignore the rest — a template pack works best when you use ten items well, not all of them once.
2. Replace every bracketed placeholder ([Business Name], [topic], [Name]) with your own details before publishing or sharing.
3. Save your customized version in one place so you can reuse it next time without starting over.
4. Review the result once in its real context — a listing, a page, or a reply — before moving on.
