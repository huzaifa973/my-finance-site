# Video Editing Keyboard Shortcuts Cheat Sheet

Premiere Pro vs DaVinci Resolve vs CapCut. On Mac, Ctrl becomes Cmd unless noted.
Print this page or keep it on a second screen while editing.

## Transport controls (8)

| Action | Premiere Pro | DaVinci Resolve | CapCut |
|---|---|---|---|
| Play / Pause | Space | Space | Space |
| Shuttle reverse / pause / forward | J / K / L | J / K / L | J / K / L |
| Go to start / end of timeline | Home / End | Home / End | Home / End |
| Step one frame back / forward | Left / Right arrows | Left / Right arrows | Left / Right arrows |
| Play around current position | Shift+K | / (slash) | — |
| Loop playback | Ctrl+L | Ctrl+/ | — |
| Go to In / Out point | Shift+I / Shift+O | Shift+I / Shift+O | — |
| Full-screen preview | ` (backtick) | Ctrl+F | — |

## Learn-first list (start here)

1. Space — play/pause
2. Cut key (C / Ctrl+\ / Ctrl+B)
3. Ctrl+Z — undo
4. Ripple delete — remove and close the gap
5. I / O — mark in and out
6. + / − — zoom the timeline
7. M — drop a marker
8. Ctrl+R — change clip speed
9. Ctrl+S — save (make it a reflex)
10. J-K-L — shuttle through footage fast
