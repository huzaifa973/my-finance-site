# Image Size Cheat Sheet for Every Social Platform (2026)

Free resource from DollarWise (dollarwise.xyz). Recommended sizes below; minimum sizes work but recommended sizes look sharpest after platform compression.

## Instagram

- Feed post (square): 1080 x 1080 px, 1:1
- Feed post (portrait): 1080 x 1350 px, 4:5 (gets the most feed space)
- Feed post (landscape): 1080 x 566 px, 1.91:1
- Story: 1080 x 1920 px, 9:16
- Reel: 1080 x 1920 px, 9:16
- Reel cover: 1080 x 1920 px, 9:16 (also shown cropped to 1:1 in the profile grid)
- Profile photo: 320 x 320 px, 1:1, displayed as a circle
- Carousel images: same as feed posts, 1080 px wide

Safe zones: Story/Reel — keep text and key elements within the central 1080 x 1420 px area; the top 250 px and bottom 250 px are covered by the profile header, reply box, and action buttons. Profile photo — keep faces and logos centered; the circular crop cuts the corners.

## Facebook

- Feed post: 1200 x 630 px, 1.91:1
- Story: 1080 x 1920 px, 9:16
- Page cover: 820 x 312 px desktop (2.7:1); mobile crops to 640 x 360 px
- Event cover: 1920 x 1005 px, 1.91:1
- Group cover: 1640 x 856 px, 1.91:1
- Profile photo: 170 x 170 px desktop, 128 x 128 px mobile, 1:1, displayed as a circle

Safe zones: Page cover — on mobile the sides are cropped, so keep text and logos within the central 640 px width. Profile photo — circular crop; center the subject.

## X

- Post image: 1600 x 900 px, 16:9 (also accepts 1200 x 675 px)
- Header: 1500 x 500 px, 3:1
- Profile photo: 400 x 400 px, 1:1, displayed as a circle

Safe zones: Header — on mobile the bottom is partially covered by the profile photo; keep important content in the upper two-thirds. Post images display up to 16:9 in the feed; taller images get cropped in the timeline preview.

## YouTube

- Thumbnail: 1280 x 720 px, 16:9 (minimum 640 px wide; under 2 MB)
- Channel banner: 2560 x 1440 px, 16:9
- Channel profile: 800 x 800 px, 1:1, displayed as a circle
- End screen elements sit inside the video frame — keep the outer 10 percent clear

Safe zones: Channel banner — the critical safe area is the central 1546 x 423 px; only this zone is visible on all devices (TV shows the full image, desktop shows 2560 x 423 px, mobile shows 1546 x 423 px). Put all text and logos inside the 1546 x 423 px center. Thumbnails — the bottom-right corner is covered by the video duration badge; keep text clear of it.

## TikTok

- Video: 1080 x 1920 px, 9:16
- Profile photo: 200 x 200 px minimum, 1:1, displayed as a circle

Safe zones: Keep text and key visuals within the central 1080 x 1500 px area. The right side (about 150 px wide) is covered by like/comment/share buttons, the bottom 300 px by the caption and music bar, and the top 150 px by the search and status area.

## LinkedIn

- Post image: 1200 x 627 px, 1.91:1
- Profile banner: 1584 x 396 px, 4:1
- Company page cover: 1128 x 191 px (approx 5.9:1)
- Company logo: 300 x 300 px, 1:1
- Profile photo: 400 x 400 px, 1:1, displayed as a circle

Safe zones: Profile banner — the bottom-left is covered by the profile photo; keep the left 400 px mostly clear and put headlines toward the center-right.

## Pinterest

- Standard Pin: 1000 x 1500 px, 2:3 (best performing ratio)
- Square Pin: 1000 x 1000 px, 1:1
- Long Pin: 1000 x 2100 px, 1:2.1 (taller pins may be cropped in feeds)
- Profile cover: 800 x 450 px, 16:9
- Profile photo: 165 x 165 px, 1:1, displayed as a circle

Safe zones: The 2:3 ratio is the sweet spot — much taller and Pinterest truncates the Pin in feeds. Keep titles in the top half; the bottom shows the Pin title and source overlay.

## General tips

- Export photos as JPG (quality 80-90) and graphics with text as PNG.
- Never upscale a smaller image to reach these sizes; design at full size.
- All platforms compress uploads — starting from the recommended size gives the cleanest result.
- Check this sheet yearly; platforms adjust layouts and these numbers drift over time.
