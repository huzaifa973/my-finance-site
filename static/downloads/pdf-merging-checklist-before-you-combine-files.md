PDF Merging Checklist: Before You Combine Files — free resource from DollarWise

1. Collect every file you plan to merge into one folder before you start.
2. Confirm each source file opens without errors or password prompts.
3. Remove any password protection from files you own and are allowed to edit.
4. Check that no source file is still open in another program that could lock it.
5. Rename files with a clear order prefix, like 01-cover, 02-report, 03-appendix.
6. Sort files in the exact reading order the final document should follow.
7. Decide whether the cover page, table of contents, or title page goes first.
8. Check page orientation: flag any landscape pages mixed into portrait documents.
9. Rotate any upside-down or sideways pages before merging, not after.
10. Remove blank pages that scanners and exports often leave behind.
11. Delete duplicate pages caused by overlapping scans or repeated exports.
12. Check that all pages use a consistent size, or note where sizes will change.
13. Confirm fonts are embedded in files you received from others, so text displays correctly.
14. Decide whether to keep original bookmarks or build a new outline for the merged file.
15. Choose your merge tool and confirm it works entirely in your browser if privacy matters.
16. Back up the original files in a separate folder before merging, just in case.
17. Merge a small test batch first when combining more than twenty files.
18. Watch for files that fail to import and replace them with a fresh export.
19. Set the merged file's title and author metadata to something meaningful.
20. Add or rebuild bookmarks for each section so readers can jump between chapters.
21. Add page numbers if the merged document will be printed or formally shared.
22. Decide on a header or footer, such as a document title or confidentiality note.
23. Choose a compression level: lighter for email, higher quality for print.
24. Check the final file size against your email or upload limit before sharing.
25. Keep hyperlinks working: verify links in the table of contents still jump correctly.
26. Open the merged file and scroll through every page, not just the first few.
27. Confirm the page order matches your planned order from start to finish.
28. Check that no pages are cut off, squashed, or stretched after the merge.
29. Confirm images and charts look sharp and are not pixelated by compression.
30. Test that form fields still work if any source file contained fillable forms.
31. Verify digital signatures are still valid, or re-sign if the merge broke them.
32. Check that the merged file's page count equals the sum of the source pages.
33. Look for stray blank pages introduced between sections during the merge.
34. Confirm the table of contents page numbers match the new pagination.
35. Run a text search for a key phrase from each section to confirm nothing is missing.
36. Save the merged file with a clear, dated filename, like report-2026-merged.pdf.
37. Store the merged file in the same folder system as the originals, not on your desktop.
38. Keep the original separate files for at least 30 days after sharing the merged version.
39. Send a test copy to yourself first when emailing, and open it on another device.
40. Confirm recipients can open the file: avoid exotic PDF versions for wide sharing.
41. Add a short note in your email or message explaining what the merged file contains.
42. Record the merge in your filing system, noting the date and the source files used.
43. Archive the merged file with the project or case it belongs to, not in a generic folder.
44. Delete working copies and temporary exports once the final file is confirmed good.
45. If the file is large, share a link to cloud storage instead of an email attachment.
46. Set sharing permissions correctly: view-only for readers, edit only for collaborators.
47. Check accessibility: text should be selectable, not scanned images, where possible.
48. Add alt text or document tags if the file will be published or shared publicly.
49. Review once more for sensitive pages that should not have been included.
50. Confirm the final file opens on both a computer and a phone before you call it done.
