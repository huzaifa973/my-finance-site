## Quick usage tips

- **Instagram/TikTok bios:** dividers (─ • ◆) and sparkles (✦ ★) format bio lines without images.
- **YouTube titles:** arrows (➜ →) and stars (★) lift click-through, but use at most one per title.
- **Checklists and notes:** ✓ ✗ ☐ ☑ turn plain text into scannable task lists.
- **Headings and dividers:** ─── ✦ ─── makes clean section breaks in plain-text posts.
- **Warning:** some symbols render as emoji on phones (❤, 💕) and as text on desktops — test on both before using in a logo or brand asset.
- **Accessibility:** screen readers read out symbol names ("black heart"), so don't build meaning from symbols alone.
