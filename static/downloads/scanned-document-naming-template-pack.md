# Scanned Document Naming Template Pack — free download from DollarWise (dollarwise.xyz)

A date-first naming system for scanned documents: one formula, eight folders, and examples you can copy today.

## The naming formula

YYYY-MM-DD_Category_Document-Name_Version.pdf

Example: 2026-10-25_Tax_W2-Form_v1.pdf

## Naming rules

1. Start with the date (year-month-day) so files sort chronologically on any device.
2. Use one category word: Tax, Work, Home, Medical, School, Finance, Legal, Travel.
3. Use hyphens inside names, underscores between sections, and no spaces.
4. End with a version: v1, v2, final. Never use names like final-final2.pdf.
5. Keep names under 50 characters so they display fully on phones.

## Category folders

- Tax: returns, W2s, receipts, deduction records
- Work: contracts, pay slips, offer letters, certificates
- Home: leases, bills, warranties, insurance
- Medical: reports, prescriptions, vaccination records
- School: transcripts, certificates, admission letters
- Finance: statements, loan papers, investment records
- Legal: agreements, IDs, registrations
- Travel: passports, tickets, visas, bookings

## Scanning tips

- Scan at 300 DPI for documents you may need to print; 150 DPI is enough for reference copies.
- Scan in grayscale unless color matters (signatures, stamps, photos).
- Name the file immediately after scanning — unnamed scans are how folders become unusable.
- Run text recognition (OCR) on scans so you can search them later.
- Back up named scans in a second location every month.
