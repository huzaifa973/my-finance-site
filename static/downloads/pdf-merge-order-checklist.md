# PDF Merge Order Checklist — free download from DollarWise (dollarwise.xyz)

Work through this checklist in order every time you combine PDFs. It prevents the most common merge problems: wrong page order, missing pages, mixed sizes, and files too large to send.

## Before you merge

1. Decide the final reading order before you touch any file — the cover page first, then chapters in order.
2. Rename files with a number prefix (01-cover, 02-chapter-1) so the order is obvious at a glance.
3. Check that every file opens correctly and is not password-protected or corrupted.
4. Confirm all pages use the same orientation; rotate sideways pages before merging.
5. Remove blank pages, duplicate scans, and draft pages you do not want in the final file.
6. Check page sizes: mixed letter and A4 pages look messy when printed.
7. Decide whether to keep color pages in color or convert everything to grayscale.
8. Merge in small batches if the files are large, then merge the batches together.

## During the merge

9. After merging, scroll through the whole document once to catch out-of-order pages.
10. Check that bookmarks or a table of contents still point to the right pages.
11. Verify page numbers run in order, especially where chapters were scanned separately.
12. Compress the merged file if it is too large to email or upload.
13. Save the merged file with a clear name and the date, and keep the originals.
14. Test-print the first and last pages before printing the whole document.
15. If the file is for someone else, add a short cover note explaining what it contains.
16. Double-check that no personal notes or annotations were left in the margins.

## After you merge

17. Confirm the file size meets the upload limit of wherever it will be submitted.
18. Back up the final merged PDF in a second location before deleting working files.
19. If pages were scanned, run text recognition so the merged file is searchable.
20. Do a final open-and-scroll check on a phone, since many readers will use one.
21. Make sure fonts are embedded so the file looks the same on other computers.
22. Check that hyperlinks inside the document still work after merging.
23. Remove metadata you do not want to share, like author names or editing history.
24. If the document will be signed, merge first and sign last — never the reverse.
25. Confirm the merged file is the final version before sending it anywhere.
26. Keep a one-line log of what was merged, in case you need to rebuild it later.
27. Verify that color signatures and stamps survived the merge at full quality.
28. Check the last page: merged files often gain a stray blank page at the end.
