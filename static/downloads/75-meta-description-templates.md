## Quick rules for every description

- Keep it between 120 and 155 characters so Google rarely truncates it.
- Front-load the target keyword — searchers scan the first words.
- Include one specific detail (a number, a year, a promise) to earn the click.
- Match the search intent: don't promise a tutorial on a definition page.
- Write a unique description for every important page; never leave it auto-generated.
- End with an implied CTA: learn, compare, discover, see, find.
