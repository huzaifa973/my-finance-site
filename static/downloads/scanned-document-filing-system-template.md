Scanned Document Filing System Template — free resource from DollarWise

1. Main folder: 01-Identity — passports, ID cards, birth certificates, and visas.
2. Main folder: 02-Finance — bank statements, tax returns, loan documents, and pay slips.
3. Main folder: 03-Home — property deeds, leases, insurance policies, and utility bills.
4. Main folder: 04-Vehicles — registration, insurance, service records, and purchase papers.
5. Main folder: 05-Health — medical records, prescriptions, vaccination cards, and test results.
6. Main folder: 06-Education — diplomas, certificates, transcripts, and training records.
7. Main folder: 07-Work — contracts, offer letters, performance reviews, and references.
8. Main folder: 08-Business — invoices, receipts, licenses, and client agreements.
9. Main folder: 09-Legal — wills, powers of attorney, court papers, and notarized documents.
10. Main folder: 10-Family — children's records, school papers, and family correspondence.
11. Main folder: 11-Travel — tickets, itineraries, hotel confirmations, and travel insurance.
12. Main folder: 12-Misc — warranties, manuals, and anything that fits nowhere else.
13. Subfolder pattern for Finance: by year, then by account or type — Finance/2026/Bank-Statements.
14. Subfolder pattern for Health: by person, then by year — Health/Your-Name/2026.
15. Subfolder pattern for Home: by property or address — Home/Main-House/Insurance.
16. Subfolder pattern for Vehicles: by vehicle — Vehicles/Car-2021/Insurance.
17. Subfolder pattern for Work: by employer or client — Work/Employer-Name/Contracts.
18. Subfolder pattern for Business: by year, then by client — Business/2026/Client-Name.
19. Subfolder pattern for Education: by person, then by institution.
20. Subfolder pattern for Legal: by matter — Legal/Will-2025, Legal/House-Purchase.
21. Subfolder pattern for Travel: by trip — Travel/2026-Trip-Destination.
22. Subfolder pattern for Family: by child or member, then by school year.
23. Subfolder pattern for Identity: by person — Identity/Your-Name/Passport.
24. Subfolder pattern for Misc: by category — Misc/Warranties, Misc/Manuals.
25. Naming rule: start every filename with the date in YYYY-MM-DD format.
26. Naming rule: follow the date with a short document type, like Invoice, Contract, or Receipt.
27. Naming rule: add the sender or subject next, like 2026-03-14-Invoice-Electric-Company.pdf.
28. Naming rule: use hyphens, not spaces, so filenames work everywhere without errors.
29. Naming rule: keep filenames under 60 characters so they display fully on all devices.
30. Naming rule: never use vague names like scan001, document, or final-version-2.
31. Naming rule: add a version suffix only when a document is genuinely revised, like v2.
32. Naming rule: keep the original language of the document in the filename when relevant.
33. Naming rule: put the most important search word early in the filename.
34. Naming rule: use the same abbreviations every time — Inv for invoice, Rcpt for receipt.
35. Scan at 300 DPI in color for documents you may need to print again later.
36. Scan at 200 DPI in grayscale for everyday reference documents to save space.
37. Save scans as PDF for multi-page documents and as searchable PDF when your scanner offers OCR.
38. Run OCR on every scan so the text inside is searchable, not just a picture.
39. Check each scan before filing: confirm all pages are present, upright, and readable.
40. Scan both sides of double-sided documents, and check the back pages are not blank.
41. File each scan immediately after scanning — never leave files in a 'to sort' folder.
42. Review the Misc folder every three months and move items into proper folders.
43. Back up the whole filing system to a second location, like an external drive or cloud storage.
44. Once a year, review folders for documents you no longer need to keep and archive or shred them.
45. Keep originals of legal and identity documents even after scanning — a scan is a copy, not a replacement.
46. Use the same system on every device so a file scanned on your phone lands in the same folders.
47. Share the system with family members or colleagues who file documents for you.
48. Test the system: pick five documents you filed last month and time how fast you find them.
49. Back up scanned identity documents separately in an encrypted folder.
50. Label physical folders to match the digital folder names, so paper and digital stay in sync.
