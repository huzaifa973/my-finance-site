# YouTube Video Description Template Pack (4 Templates)

Copy a template, fill in the bracketed parts, and paste it into the description box when you upload. Keep the first 2-3 lines keyword-rich — that's what viewers see before clicking "show more."

## Quick rules for every description

- Front-load keywords: the first 150 characters show in search results — put the topic and promise there.
- Repeat the main keyword 2-3 times naturally in the full description for SEO.
- Add timestamps: they create "key moments" in Google and boost watch time.
- Always include one clear CTA (subscribe, comment, or click a link) — descriptions without CTAs waste the space.
- Disclose affiliate links and sponsorships plainly; it's required by the FTC and builds trust.
- End with 3-5 hashtags: the first 3 appear above your video title.
