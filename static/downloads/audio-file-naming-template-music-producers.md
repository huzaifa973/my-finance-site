# Audio File Naming Template for Music Producers — free download from DollarWise (dollarwise.xyz)

The system is: Artist — Project — Element — Version — Date, always in that order, always with the same separators. Version numbers beat words like “final” (final is a lie the moment you reopen the file), and dates beat memory. The examples below show the pattern applied to real session files.

THE SYSTEM
Order: Artist — Project — Element — Version — Date
Separators: hyphens between parts, no spaces
Versions: v01, v02, v03 — never “final”, “new”, or “latest”
Dates: YYYY-MM-DD, always at the end before the extension
Samples add: BPM and key, e.g. 120BPM-Cmin
Masters add: loud or streaming variant, e.g. Master-Loud, Master-Streaming
