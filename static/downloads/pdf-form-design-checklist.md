# PDF Form Design Checklist: Build Forms People Actually Complete

25 rules for forms that get filled out instead of abandoned.

## Layout and flow (6 rules)

1. One column, top to bottom — multi-column forms break the natural reading flow.
2. Group related questions under clear section headings (Personal details, Payment, etc.).
3. Put the easiest questions first — early momentum carries people through harder fields.
4. Save sensitive questions (income, ID numbers) for later in the form.
5. Show progress on long forms: section numbers or a progress bar.
6. Keep the submit button visible and labeled with the outcome: "Send application", not "Submit".

## Labels and instructions (5 rules)

7. Label every field in plain words: "Phone number" beats "Tel. (primary)".
8. Put labels ABOVE fields, not beside them — above survives narrow screens.
9. Add a one-line hint for any field that isn't obvious: "MM/YYYY", "As shown on your ID".
10. Mark required fields with an asterisk AND explain it once at the top: "* Required".
11. Use the audience's vocabulary — if they say "cell", don't label it "mobile handset".

## Field design (5 rules)

12. Match the field to the answer: radio buttons for 2–5 options, dropdowns only for 6+.
13. Use date pickers for dates, not three separate day/month/year boxes.
14. Make text areas grow with content — cramped boxes discourage complete answers.
15. Make fields at least 44px tall for touch; cramped fields get abandoned on phones.
16. Pre-fill anything you already know — never ask twice for the same information.

## Validation and errors (5 rules)

17. Validate as the user types — never save all errors for the submit button.
18. Write specific error messages: "Enter a 10-digit phone number" beats "Invalid input".
19. Never clear a form on error — keep everything the user already entered.
20. Confirm format expectations BEFORE submission (password rules, file size limits).
21. On success, show a confirmation page or message — don't leave people guessing.

## Accessibility (4 rules)

22. Make every field keyboard-navigable in logical tab order.
23. Give every field a real label (not just placeholder text) for screen readers.
24. Keep label-to-field contrast high — light gray placeholder text is not a label.
25. Test the full fill on a real phone before you publish the form.

## The 60-second form audit

- [ ] Can it be completed in under 3 minutes?
- [ ] Is every required field truly required?
- [ ] Does it work on a phone without pinching or zooming?
- [ ] Do errors explain exactly how to fix them?
- [ ] Would YOU enjoy filling this out?
